# Quiz de connaissance biblique

Ce projet est une petite application web de quiz permettant d'évaluer les connaissances bibliques à travers une série de questions à choix unique.

## À propos

L'application a été construite avec Vite et JavaScript vanilla. Elle présente :

- une interface simple et claire
- des questions sur la Bible
- un système de score
- un bouton de démarrage et une progression dans le quiz

## Prérequis

- Node.js 18+
- npm

## Installation

```bash
cd quiz-javascripts
npm install
```

## Lancer le projet

```bash
cd quiz-javascripts
npm run dev
```

Puis ouvrez l'URL locale affichée dans le terminal (généralement http://localhost:5173).

## Construire pour la production

```bash
cd quiz-javascripts
npm run build
```

## Fonctionnement

1. Cliquer sur le bouton "Démarrer".
2. Répondre aux questions proposées.
3. Vérifier le score final et la performance.
